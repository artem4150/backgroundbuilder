# Архитектура

«Состав» — веб-конструктор векторных иллюстраций из предоставленной библиотеки SVG.

## Компоненты

- Next.js + React + TypeScript: интерфейс, SVG-холст, ручное редактирование и экспорт.
- FastAPI: каталог, выдача SVG, подбор объектов и расчёт композиции.
- Gemini 3.5 Flash-Lite: интерпретация метафоры и выбор идентификаторов существующих объектов. Модель не рисует и не генерирует SVG.
- MinIO: приватное S3-совместимое хранилище исходных вариантов. PostgreSQL хранит историю генераций: до 30 записей на анонимную сессию браузера. Снимок содержит запрос, настройки и готовую сцену; восстановление не вызывает Gemini. Текущие ручные правки остаются в памяти вкладки.
- Nginx: HTTPS, проксирование frontend/API/файлов и ограничение частоты запросов сборки.
- Docker Compose: запуск сервисов; сертификаты и файлы MinIO сохраняются в отдельных томах.

## Хранение и извлечение SVG

Каталог `frontend/app/catalog.json` связывает идентификатор объекта с исходным файлом, детализацией S/L, ролью (главный/фоновый), размерами и URL. Библиотека содержит 10 типов объектов и 40 вариантов S/L × роль. Отдельно хранятся подложки и три исходные палитры.

Подготовленные файлы загружаются в MinIO при старте backend. Клиент запрашивает их через `/media/`; backend разрешает только файлы библиотеки. S3-ключи, консоль MinIO и API-ключ Gemini не передаются браузеру. Для разработки без S3 используется чтение тех же файлов с диска.

Оригиналы не изменяются. `tools/prepare_palettes.py` создаёт цветовые варианты на основе `frontend/shared/palettes.json`. Цветовые роли разделяют фон, объекты и нейтральные цвета; геометрия SVG сохраняется.

## Переиспользование и композиция

Сцена — массив экземпляров с идентификатором объекта, координатами, углом и ролью. Один SVG можно использовать несколько раз без копирования его геометрии в модель сцены. S/L переключает соответствующий исходник; смена роли не меняет размер экземпляра.

В режиме названий используется словарь и порядок ввода. Для метафоры Gemini возвращает идентификаторы по проверяемой схеме. Одинаковые запросы кэшируются на час; после ошибки квоты применяется пауза, при недоступности модели — явно обозначенный словарный подбор.

Алгоритм компоновки учитывает формат, смысловой главный объект, поддерживающие фоновые объекты и перекрытия. Дополнительные фоновые предметы выбираются только из библиотеки. Общий масштаб применяется ко всей группе: соотношения размеров объектов не меняются. Ручные операции позволяют перемещать, поворачивать, дублировать, удалять и менять порядок слоёв.

## Экспорт

Экспорт выполняется в браузере из снимка сцены. В один SVG встраиваются исходные векторные поддеревья с трансформациями и цветами выбранной палитры. Идентификаторы масок/областей отсечения получают уникальные префиксы для каждого экземпляра. Рамки выделения и интерфейс не экспортируются; растрирование не применяется.

## Проверки и границы

13 backend-тестов проверяют API, каталог, геометрию, роли, кэш и fallback. Три frontend-теста проверяют общее масштабирование. Дополнительно выполнены браузерные проверки и разбор экспортированных SVG независимым рендерером.

Импорт SVG в авторизованную Figma ещё требует финальной ручной проверки. Художественная компоновка основана на эвристиках; пользователь может доработать сцену. Регистрация и сохранение проектов не входят в объём тестового.

## История генераций

PostgreSQL работает во внутренней сети Compose, данные сохраняются в postgres-data. Сессия привязана к случайной HttpOnly SameSite-cookie; в базе хранится её хэш. Записи другого браузера не выдаются. Сохраняются результаты генерации, а не последующие ручные правки. Новые записи автоматически вытесняют старые сверх лимита 30.
