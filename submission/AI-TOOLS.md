# Использованные AI-инструменты

- **OpenAI Codex** — помощь с проектированием, написанием и рефакторингом frontend/backend, тестами, диагностикой Docker и документацией. Полученные изменения проверялись сборкой, тестами и в браузере.
- **Google Gemini API, gemini-3.5-flash-lite** — часть работающего сервиса: смысловой подбор объектов из фиксированной библиотеки по метафоре или заголовку. Возвращает только идентификаторы, не создаёт изображения или векторные контуры.
- **Context7 MCP** — получение документации библиотек и инструментов при разработке.

Визуальные объекты взяты из предоставленных материалов Figma. Генерация новых иллюстративных объектов нейросетью не использовалась. Названия, геометрия и варианты библиотеки подготовлены по исходникам; перекраска ограничена исходными цветовыми схемами.
