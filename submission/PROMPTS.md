# Запросы для отбора примеров

Каждый запрос можно выполнить несколько раз: расположение может отличаться. Для сравнения используйте три формата, исходные палитры и переключение S/L. Фоновые объекты включены, общий масштаб начните со 100%; при необходимости увеличьте до 110–125%.

## По идеям

Вставляйте во вкладку «По идее» без кавычек.

1. Собрать разрозненные знания в единую картину и найти недостающую часть решения.
2. Превратить поток мыслей в понятный план и сделать первый шаг к новой цели.
3. Навести порядок в личных финансах и увидеть новые возможности для роста.
4. Отключиться от информационного шума и сосредоточиться на важном.
5. Найти свежую идею для сложной задачи и довести её до результата.
6. Соединить обучение, практику и творческий подход в одном процессе.
7. Сохранить важное, упорядочить дела и освободить место для новых идей.
8. Передать тёплые чувства человеку, который находится далеко.

Не требуйте точного совпадения объектов с заранее ожидаемым набором: оцените смысловую связь и качество композиции. Если статус сообщает о словарном подборе, это fallback, а не успешный ответ Gemini.

## Рекомендуемые три примера для отправки

- Обучение: «пазлы, книга, ручка», горизонтальный, L, Лаванда.
- Финансы: «кошелёк, монета», вертикальный, L, Персик.
- Сосредоточенность: «наушники, тюльпаны», квадратный, S, Бирюза.

Выберите по одному лучшему результату, при необходимости вручную поправьте положение. Проверяйте, что главный предмет узнаваем, фоновые предметы не обрезаны до неузнаваемости, а мелкие элементы не перекрывают важные детали. Скачайте именно SVG; PNG-превью в комплекте служат только для удобного просмотра.
