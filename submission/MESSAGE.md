Подготовил тестовое задание — веб-сервис «Состав» для автоматической сборки векторных композиций из предоставленной библиотеки.

- Работающий сервис: https://backgroundbuilder.duckdns.org/
- Исходный код: https://github.com/artem4150/backgroundbuilder
- Короткая демонстрация и примеры: папка `submission` в репозитории, файл `demo.html`.
- Архитектура: `submission/ARCHITECTURE.md`.
- Использованные AI-инструменты: `submission/AI-TOOLS.md`.
- Три готовые композиции в SVG: `submission/examples`.

Реализованы подбор по метафоре и названиям компонентов, детализация S/L, исходные цветовые схемы, главные и фоновые объекты, ручное редактирование слоёв и экспорт SVG без растрирования. Для запуска предусмотрены Docker Compose и инструкция в README.
