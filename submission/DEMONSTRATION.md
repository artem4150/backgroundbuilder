# Короткая демонстрация: 90–120 секунд

Сервис: https://backgroundbuilder.duckdns.org/

1. **0:00–0:25. Подбор по метафоре.** Вкладка «По идее», запрос: «Собрать разрозненные знания в единую картину». Нажать «Собрать композицию», дождаться результата. Если показан словарный fallback, сообщить об этом; не выдавать его за Gemini.
2. **0:25–0:45. Подбор по названиям.** Вкладка «Объекты», запрос «кошелёк, монета». Показать полученную сцену с фоновой лампой. Отключить фоновые объекты и собрать снова для сравнения.
3. **0:45–1:05. Варианты.** Переключить S/L, исходную палитру и формат. После изменения формата собрать композицию заново. Показать общий масштаб композиции.
4. **1:05–1:30. Ручное редактирование.** Выделить и переместить предмет, повернуть, продублировать, изменить слой, удалить копию. Показать главный/фоновый вариант.
5. **1:30–1:50. Экспорт.** Скачать SVG, открыть его в браузере. При наличии авторизованной Figma импортировать и показать редактирование векторных элементов.

## Готовая демонстрационная страница

Открыть `demo.html`: три композиции, параметры сборки, SVG для скачивания и ссылка на работающий редактор. Это краткая интерактивная презентация результатов, не видеозапись экрана.

Видеофайл пока не записан. Этот сценарий можно использовать для короткого скринкаста при необходимости.
